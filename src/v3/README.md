# Routefinder V3 Product Area

This directory is the clean boundary for future V3 product work.

V2 remains frozen elsewhere in the repository, including the quiz, route scoring, roadmap, simulator, and application-readiness workspace. Do not import V2 product types, scoring logic, or workflow assumptions into this area unless a deliberate migration decision explains why they apply.

V3 is not designed or implemented during Phase 0. Start from the active [`docs/product-direction.md`](../../docs/product-direction.md) and the [`docs/v3-reset.md`](../../docs/v3-reset.md) migration boundary, then derive types and architecture from user validation.
